## 🎯 The Core Problem

When a developer leaves a team, critical institutional knowledge gets lost. The successor engineer spends weeks digging through commit messages, closed PRs, and abandoned issues just to piece together:
- Who actually built and maintains what module?
- What features are half-finished or blocked?
- Why were key architectural decisions made?
- What are the undocumented deployment traps, credentials, and single points of failure?

**HandoverIQ automates this entire transition in seconds.**

---

## ⚡ The Solution

Connect any public or private GitHub repository → HandoverIQ collects raw project activity → analyzes the work using structured AI reasoning → delivers an authoritative, evidence-linked Handover Intelligence Report organized across **5 Core Pillars**:

1. 👤 **Ownership & Core Modules**: Active contributors, domain experts, and file ownership patterns.
2. 🚧 **Unfinished Work & In-Flight Tasks**: Active PRs, draft branches, and blocked issues.
3. 🏛️ **Architectural Decisions & Context**: The "why" behind changes documented in commit messages and PR conversations.
4. 📦 **Dependencies & Setup Context**: Primary runtime stacks, configuration files, and tools touched.
5. ⚠️ **Risks, Tech Debt & Blockers**: Defect clusters, single points of failure, and stale items.

### 🛡️ Strict Evidence Linking (No AI Hallucinations)
Every single insight generated by HandoverIQ is permanently linked to verified GitHub proof (direct commit SHA, pull request number, or issue URL).

### 🔍 Knowledge Gap Detection & Reviewer Checklist
Identifies blindspots (e.g., missing staging credentials, undocumented migration steps) with interactive **"Mark Resolved"** toggles and the ability to add custom handover questions.

## 🚀 Getting Started Locally

### 1-Click Launch (Windows)
Double-click:
```cmd
start-all.bat
```
* **Frontend**: http://localhost:3000
* **Backend**: http://localhost:8000
* **Interactive API Docs**: http://localhost:8000/docs

### Manual Launch

**Terminal 1 — Backend:**
```cmd
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

**Terminal 2 — Frontend:**
```cmd
cd frontend
npm install
npm run dev
```
